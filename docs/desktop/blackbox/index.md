# 

## Hotkeys

Open Preferences
`ctrl + ,`

Close tab
`shift + ctrl + w`

Focus next tab
`ctrl + tab`

Focus previous tab
`shift + ctrl + tab`

Keyboard shortcuts
`shift + ctrl + ?`

New Tab
`shift + ctrl + T`
